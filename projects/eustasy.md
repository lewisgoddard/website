Open-source code I've built and maintained under the [eustasy](https://github.com/eustasy) org. Mostly small, single-purpose libraries and scripts that solve a specific operational problem.

### [Bubbly](https://github.com/eustasy/Bubbly) &middot; 217&#9733;

Better SSL in nginx in 10 minutes. Configuration files and setup scripts for Certbot &mdash; Let's Encrypt + nginx, distilled to the steps that actually work.

### [Phoenix](https://github.com/eustasy/Phoenix) &middot; 18&#9733;

A lightweight BitTorrent tracker written in PHP with an SQL backend. Designed to drop in next to an existing site without dragging in a full tracker stack.

### [authenticatron](https://github.com/eustasy/authenticatron) &middot; 11&#9733;

A small PHP library for HOTP / TOTP &mdash; secret generation, QR-code provisioning, and code verification. For sites that want second-factor auth without a heavyweight library.

### [Colors.css](https://github.com/eustasy/Colors.css) &middot; 8&#9733;

A colour-system stylesheet &mdash; backgrounds and fonts from named palettes (Material, Tailwind, and the `goddardhale` palette this site uses).

### [browning](https://github.com/eustasy/browning) &middot; 3&#9733;

A tiny PHP function to send emails through Mailgun via cURL &mdash; an alternative to Mailgun's heavier official library.

### [puff-server](https://github.com/eustasy/puff-server) &middot; 3&#9733;

Centralised sign-on, access control, and unified billing across multiple organisations. Alpha.
